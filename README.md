# Math Teacher AI

## منصة تعليمية ذكية لمعلمي الرياضيات

Math Teacher AI is an AI-powered educational platform designed to help mathematics teachers prepare lessons, generate worksheets and quizzes, and analyze student performance using specialized AI agents.

---

## 1. Project Overview

يهدف المشروع إلى مساعدة معلم الرياضيات على تقليل الوقت والجهد المستغرق في إعداد المحتوى التعليمي وتحليل نتائج الطلاب، من خلال منصة واحدة تعتمد على الذكاء الاصطناعي ووكلاء متخصصين.

بدلاً من استخدام أدوات منفصلة لكل مهمة، توفر المنصة مجموعة من الوكلاء الذكيين لتنفيذ المهام التعليمية المختلفة.

---

## 2. Problem

يواجه معلم الرياضيات عدة تحديات يومية، منها:

- الوقت الطويل اللازم لإعداد الدروس.
- إعداد أوراق العمل والاختبارات.
- إنشاء أسئلة متنوعة بمستويات صعوبة مختلفة.
- تحليل نتائج الطلاب.
- الحاجة إلى أدوات متعددة لتنفيذ هذه المهام.
- تحويل البيانات التعليمية إلى معلومات تساعد في اتخاذ القرار.

---

## 3. Target Users

المستخدم الأساسي للنظام هو:

- معلمو الرياضيات.
- معلمو المرحلة المتوسطة.
- المعلمون الراغبون في استخدام الذكاء الاصطناعي في التخطيط والتقويم وتحليل البيانات.

---

## 4. Solution

يقدم Math Teacher AI منصة تعليمية ذكية تجمع مجموعة من أدوات الذكاء الاصطناعي في نظام واحد.

يمكن للمعلم استخدام المنصة من أجل:

1. إعداد خطة درس.
2. إنشاء ورقة عمل.
3. إنشاء اختبار.
4. تحليل نتائج الطلاب.
5. الحصول على مخرجات تعليمية منظمة وقابلة للاستخدام.

---

# 5. AI Agents

يعتمد النظام على مجموعة من الوكلاء المتخصصين:

### Lesson Agent

وكيل متخصص في إنشاء خطط الدروس.

يقوم بتحليل بيانات الدرس مثل:

- الصف الدراسي.
- المادة.
- موضوع الدرس.
- مدة الحصة.
- عدد الطلاب.
- استراتيجية التدريس.

ثم يقوم بإنشاء خطة درس منظمة تتضمن الأهداف والأنشطة والتقويم.

---

### Worksheet Agent

وكيل متخصص في إنشاء أوراق العمل التعليمية.

يقوم بإنشاء أسئلة مناسبة للصف والدرس ومستوى الصعوبة، مع إمكانية إعداد مخرجات مناسبة للطباعة.

---

### Quiz Agent

وكيل متخصص في إنشاء الاختبارات.

يمكنه إنشاء اختبار وفق:

- عدد الأسئلة.
- نوع الأسئلة.
- مستوى الصعوبة.
- توزيع الدرجات.
- موضوع الدرس.

---

### Analytics Agent

وكيل متخصص في تحليل بيانات الطلاب.

يستقبل بيانات النتائج ويحولها إلى تحليلات تساعد المعلم على:

- معرفة مستوى الطلاب.
- اكتشاف نقاط القوة والضعف.
- متابعة الأداء.
- دعم اتخاذ القرار التعليمي.

---
